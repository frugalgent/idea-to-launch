# Nuances — [PROJECT NAME]
Required states for every feature. No feature is "done" without all four.

## The four states
- **Loading** — only if genuinely loading; inline > full-page; announced + reduced-motion safe
- **Error** — says what + how to fix, next to the field; PRESERVES user input
- **Empty** — in brand voice: "[your empty-blog line]" / "[your empty-listing line]"
- **Success** — confirms + what happens next: "[your confirmation line]"

## Motion rules
Must mean something · fast and subtle · focus states sacred · reduced-motion always

## Standing smell test
A full-page spinner on a static page = performance bug. Fix the cause, not the optics.

## The unglamorous set (all exist, all in-voice, all tested)
404 · thank-you · form error + success · favicons · share cards · touch icons
