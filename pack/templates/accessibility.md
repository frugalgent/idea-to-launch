# Accessibility Rules — [PROJECT NAME]

## Contrast
- Body text meets WCAG AA against [your background]; check [risky color pairs] on every use
- Never convey meaning by color alone

## Images
- Every image has alt text, HUMAN-REVIEWED
- Decorative images: empty alt, on purpose

## Keyboard
- Everything reachable by Tab, sensible order; focus states styled, never removed
- Skip-to-content link on every page

## Structure
- Semantic HTML: one h1 per page, ordered headings, landmarks
- Forms: labels tied to inputs; errors announced, adjacent, input-preserving

## Motion
- Everything honors prefers-reduced-motion with a calm alternative
- Loading states announced to screen readers
