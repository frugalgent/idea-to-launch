# Nuances — Marisol's Kitchen
Required states for every feature. No feature is "done" without all four.

## The four states
- **Loading** — only if genuinely loading; inline > full-page; announced + reduced-motion safe
- **Error** — says what went wrong and how to fix it, next to the field; PRESERVES user input
- **Empty** — in brand voice, offers a next step ("First post coming soon — meanwhile, the menu")
- **Success** — confirms + says what happens next, in brand voice

## Motion rules
Must mean something · fast and subtle · focus states sacred · reduced-motion always

## Standing smell test
A full-page spinner on a static page = performance bug. Fix the cause, not the optics.

## The unglamorous set (all exist, all in-voice, all tested)
404 · thank-you/confirmation · form error + success · favicons · share cards · touch icons
