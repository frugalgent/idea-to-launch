# Design System — Marisol's Kitchen
Every kept choice becomes a rule. Rules live here so they travel to every session.

## Color (derived from the actual business)
- clay:     #B4552D   headings, accents — from the comal
- masa:     #F6EFE3   background — from the tortillas
- charcoal: #2A2622   body text
- agave:    #5C7350   links, confirmations — from the window plants
DON'T: gradients, pure white backgrounds, purple. Ever.

## Type
- Display: warm serif, weight 600 — headlines only
- Body: humanist sans, 17px / 1.6, max measure ~70ch

## Spacing
- Base unit 8px; sections breathe at 64px+
- DON'T cram cards; when in doubt, add space

## Components
- Menu items: recipe-card treatment (signature element — see anti-slop.md; protect it)
- Buttons: solid clay, charcoal text on hover, visible focus ring always

## States (design these on purpose — see nuances.md)
Empty · long-name (45+ chars) · missing-image · error — every component survives all four
