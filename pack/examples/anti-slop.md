# Anti-Slop Rules — Marisol's Kitchen
An unguided model outputs the average of the internet. These rules steer off the mean.

## Banned visual patterns
- Gradients of any kind; purple anywhere
- Stock hero + three-feature-cards layout
- Icons standing in for real photos
- Any imagery that isn't ours (real phone photos only — cleaned up, never synthetic)

## Banned words
elevate · seamless · experience (as a noun) · authentic · passion(ate) ·
culinary journey · "we pride ourselves"

## Signature element (protect it)
Menu styled as grandmother's 1962 recipe cards — never "clean up" the card
texture or the handwritten section headers.

## The test (run before shipping any page)
Could this element appear, unchanged, on another restaurant's site?
If yes, it's not done.
