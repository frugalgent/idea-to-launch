# Errata

Corrections to the book's text, organized by chapter, newest first within each
chapter. Every entry is dated and names the edition it corrects.

**Found an error?** File an issue with: the chapter, the passage (quote a few
words so we can find it), what's wrong, and — if you know it — what's right.
You are the early-warning system, and we're grateful for it.

**How to read the flags:**
- `[FIX]` — the book said something incorrect
- `[TOOL CHANGE]` — the book was right when written; the tool moved (check
  `CHANGELOG.md` and the relevant repo file for the current facts)
- `[CLARIFICATION]` — technically correct but confusing enough to correct anyway
